How to write a filter
  • It's matched against the .ipk file names in each release, ignoring case. Any part of the name is enough.
  • Write \. for a dot and \+ for a plus; they have other meanings on their own.
  • .* means "anything", e.g. for the version number. $ means "end of name".
  • webOS22\+\.ipk$ picks app_1.2.3_all_webOS22+.ipk
  • _all\.ipk$ picks app_1.2.3_all.ipk but not the webOS22+ one
  • ^(?!.*webOS22) picks any file without "webOS22" in its name
