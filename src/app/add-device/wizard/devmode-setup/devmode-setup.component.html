Do following steps to get ready for setting up connection to your TV.

You'll need an LG Developer account to use Developer Mode.

  1. In your browser, open LG's Developer Mode guide.
  2. Select "SIGN IN" at the top right of the page.
  3. Create an LG Developer account, or sign in if you already have one.

Then return here and continue with the TV setup below.

  1. On your TV, open LG Apps (LG Content Store)
  2. Search for "Developer Mode"
  3. Select "Install"
  1. Launch Developer Mode app
  2. Login to Developer Mode app with developer account
  3. Enable Developer Mode and wait for TV to restart
  1. Launch Developer Mode app again
  2. Ensure "Dev Mode Status" is ON
  3. Enable Key Server
