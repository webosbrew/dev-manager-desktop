Automatic Developer Mode Renewal
  • Manual Setup

    Renewing requires a command to run on the TV. Run the following from a computer on the same local network, replacing /path/to/webos_private_key with the SSH key configured for this TV. 

    ssh -i /path/to/webos_private_key -p {{ device.port }} {{ device.username }}@{{ device.host }} \
  "luna-send-pub -n 1 luna://com.webos.applicationManager/launch '{\"id\":\"com.palmdts.devmode\",\"subscribe\":false,\"params\":{\"extend\":true}}'"
    The TV must be powered on, reachable, and have an active Developer Mode session. For a command with the configured key embedded, use the Shell Script tab.
